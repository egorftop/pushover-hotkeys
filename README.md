# Pushover Hotkeys

Русскоязычное Windows-приложение: глобальная горячая клавиша отправляет уведомление в [Pushover](https://pushover.net/). Одна клавиша может отправлять уведомление нескольким получателям.

## Возможности

- Глобальные одиночные клавиши и сочетания Ctrl, Alt, Shift и Win.
- Несколько Pushover User/Group Key для одной привязки.
- Отдельные текст, срочность и звук для каждой горячей клавиши.
- Работа в системном трее и автозапуск с Windows.
- Pushover App Token и ключи получателей хранятся только на компьютере пользователя в защищённом Windows DPAPI-файле.

## Скачать и использовать

Скачайте `PushoverHotkeysSetup.exe` со страницы [Releases](../../releases) и установите приложение.

1. В [Pushover](https://pushover.net/apps/build) зарегистрируйте **своё** приложение и скопируйте его App Token.
2. Откройте «Настройки» в программе и вставьте App Token.
3. Нажмите «Добавить», запишите клавишу, укажите текст, срочность, звук и User/Group Key получателей.
4. Закройте окно — программа продолжит работать в системном трее.

Громкость задаётся настройками Pushover и самого устройства. Программа может выбрать тон Pushover, но не меняет громкость телефона или компьютера.

## Безопасность ключей

В репозитории и в релизах **нет** App Token, User Key или Group Key. Каждый пользователь вводит свои данные после установки. Локальные настройки находятся в `%LOCALAPPDATA%\PushoverHotkeys\settings.dat`, шифруются Windows DPAPI и не должны добавляться в Git.

Если ключ случайно попал в публичный коммит, отзовите его в Pushover и создайте новый: простого удаления ключа из файла недостаточно.

## Сборка из исходников

Требуются .NET SDK 8 для Windows:

```powershell
dotnet test .\PushoverHotkeys.sln
dotnet build .\PushoverHotkeys.sln -c Release
```

Для сборки установщика нужен Inno Setup 6:

```powershell
.\build-installer.cmd
```

Установщик появится в `artifacts\PushoverHotkeysSetup.exe`.
