# Pushover Hotkeys

**Нажмите горячую клавишу — Pushover сразу отправит нужное уведомление.**

Pushover Hotkeys — небольшая Windows-программа для быстрых личных уведомлений. Например: назначьте `F8` на сообщение «Я выехал», `Ctrl + F9` — на «Нужна помощь», а `F10` — на «Сервер проверен». Программа работает в системном трее и продолжает принимать горячие клавиши, даже когда её окно закрыто.

> Приложение не содержит чужих или общих Pushover-ключей. Каждый пользователь вводит свой App Token и свои ключи получателей после первого запуска.

## Что умеет

- Назначать обычные клавиши и сочетания `Ctrl`, `Alt`, `Shift`, `Win`.
- Отправлять разные тексты для разных горячих клавиш.
- Настраивать срочность и звук Pushover отдельно для каждой привязки.
- Отправлять одно уведомление нескольким User/Group Key одновременно.
- Работать в системном трее и запускаться вместе с Windows.
- Хранить Pushover-ключи локально в шифрованном Windows DPAPI-файле.

## Быстрый старт

1. Скачайте [PushoverHotkeys.exe](../../releases/latest) и сохраните его в постоянную папку. Установка не нужна.
2. Запустите файл и откройте «Настройки».
3. Создайте собственное приложение на [Pushover](https://pushover.net/apps/build), затем вставьте его **App Token**.
4. Нажмите «Добавить», запишите горячую клавишу, задайте текст, срочность, звук и User/Group Key получателя.
5. Нажмите «Сохранить». Для проверки выберите правило и нажмите «Отправить сейчас».

После закрытия основного окна программа не завершается — она остаётся в системном трее рядом с часами. Чтобы полностью выйти, нажмите правой кнопкой на значок и выберите «Выйти».

## Как работают уведомления

У каждой горячей клавиши свои параметры:

| Параметр | Пример |
| --- | --- |
| Горячая клавиша | `6` |
| Сообщение | `К ПК СУКА` |
| Срочность | Обычная или высокая |
| Звук | Pushover, Siren, без звука и другие встроенные тоны |
| Получатели | Один или несколько Pushover User/Group Key |

«Высокая» срочность обходит тихие часы Pushover. Громкость задаётся на телефоне или компьютере в настройках Pushover: программа выбирает тон, но не меняет системную громкость.

## Приватность и безопасность

- Ключи не отправляются никуда, кроме официального API Pushover при отправке уведомления.
- Файл настроек находится в `%LOCALAPPDATA%\PushoverHotkeys\settings.dat` и защищён Windows DPAPI: его может прочитать только тот же профиль Windows.
- Нажатия клавиш не записываются, не сохраняются и не блокируются. Обработчик нужен исключительно для сравнения нажатия с назначенными горячими клавишами.
- В репозитории и GitHub Releases нет App Token, User Key или Group Key.

Некоторые системные, аппаратные клавиши и приложения, запущенные от имени администратора, могут не передавать свои нажатия обычному приложению. Для надёжных сценариев лучше выбирать `F`-клавиши или сочетания с `Ctrl`/`Alt`.

## Portable-версия

Релиз распространяется одним self-contained `.exe` для Windows x64: .NET устанавливать не нужно. Если перенести файл в другую папку, просто запустите его один раз из нового места — автозапуск будет обновлён на новый путь.

## Сборка из исходников

Нужен .NET SDK 8 для Windows:

```powershell
dotnet test .\PushoverHotkeys.sln
dotnet build .\PushoverHotkeys.sln -c Release
```

Чтобы собрать portable-файл:

```powershell
.\build-portable.cmd
```

Готовый файл появится в `artifacts\PushoverHotkeys.exe`.
